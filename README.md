# からだセルフチェック

痛みと姿勢写真から、からだの使い方の「傾向」を確認し、イラスト付きの自主練習メニューを作るWebアプリです。

**アプリを開く：https://yujih0104-del.github.io/body-selfcheck/**

- シニア（転倒予防・膝や腰の痛み）と働く世代（腰痛・肩こり）を選べます。
- 運動の前に、受診が必要なサイン（レッドフラッグ）を必ず確認します。該当する場合は練習を表示せず、受診をすすめます。
- 姿勢写真は端末（ブラウザ）の中だけで処理し、外部には送信しません。初回のみAIモデルの読み込みにインターネット接続が必要です。
- 病気を診断するものではありません。結果は2次元画像からの推定値による目安です。

相談・予約の窓口（訪問ストレッチなど）は、`index.html` 先頭付近の `CONTACT` の `url` に予約フォームやLINE公式アカウントのURLを入れると、結果画面と印刷物に表示されます。
